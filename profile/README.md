# DAIGEST

**All your newsletters, filtered into one mail.**

A free skill for Claude. Every day it reads the newsletters you're subscribed to and sends you one mail: what connects across them, which ones deserve your time, and a link back to each original.

- **Get it:** https://mydaigest.github.io
- **The skill:** [mydaigest/daigest](https://github.com/mydaigest/daigest)
